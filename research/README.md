# Исследовательские инструменты

Модули анализа FEI/FEK, CPU/GPU-перебора, Z3/SMT, построения профилей PDF и частичного восстановления файлов. Основной интерфейс восстановления описан в [README проекта](../README.md).

## Структура

| Каталог | Назначение |
|---|---|
| `gpu/` | OpenCL-перебор, проверка кандидатов на CPU и сохранение прогресса |
| `legacy/` | Анализ FEI, oracle, PDF, Z3, генераторы CPU-worker'ов и salvage |
| `later/` | Подбор с масками, итеративное расширение покрытия и подготовка GPU-задач |
| `native/` | C-исходники исследовательских CPU-worker'ов и packer имён apLib |

Каталоги `legacy/` и `later/` содержат экспериментальные сценарии. Их интерфейсы и требования к входным данным различаются. Состав исходников и контрольные суммы исходных версий приведены в [inventory.json](inventory.json).

## Зависимости

Из корня репозитория:

```powershell
python -m pip install -r ./research/requirements.txt
```

Для работы с видео некоторые сценарии дополнительно требуют FFmpeg/ffprobe в PATH. Нативные helper'ы собираются GCC из MSYS2 UCRT64. Основные `brute-extend` и `direct-decrypt` устанавливаются штатным installer'ом проекта.

## Конфигурация экспериментов

Пути, имена целевых файлов и параметры конкретного набора задаются отдельным JSON-профилем. Шаблон — [case_values.example.json](case_values.example.json). Значения `REPLACE_WITH_YOUR_CASE_VALUE` необходимо заменить параметрами выбранного сценария. Идентификатор значения сопоставляется с вызовом `_case_value(...)` в исходнике.

Профиль можно сохранить как `research/case_values.json` или указать через переменную окружения:

```powershell
$env:LOCKBIT_CASE_VALUES = (Resolve-Path ./private-task/case_values.json).Path
python ./research/legacy/recover_desktop_tree.py
```

Перед запуском проверьте входы, выходной каталог и ограничения нагрузки. Некоторые сценарии дополнительно используют seed-файлы, отчёты и известные пары. Эти данные подготавливаются для конкретной задачи и не входят в репозиторий. Профиль может содержать ключевые данные, поэтому его нельзя публиковать.

В корневых инструментах `fei_layout_analysis.py` и `iterative_recovery_pairs.py` используются переменные `RECOVER_SOURCE` и `RECOVER_OUTPUT`. Анализ FEI дополнительно поддерживает `RECOVER_PAIRS` и `RECOVER_FEI_REPORTS`. Значения по умолчанию относительные.

## Нативные инструменты

Для массового исследовательского pipeline соберите packer имён:

```powershell
gcc -O2 -I ./_stream-reuse ./research/native/legacy/aplib_name_pack.c ./_stream-reuse/aplib-src/lib/coff64/aplib.lib -o ./research/legacy/aplib_name_pack.exe
```

C-шаблоны с `#include "private_case.h"` требуют header с параметрами выбранной задачи. Его можно получить соответствующим Python-генератором либо подготовить из подтверждённых входных данных. При сборке укажите каталог header через `gcc -I`. Реальные FEK, keystream и эталонные блоки храните вне Git.

## GPU-перебор

[gpu/recover_gpu.py](gpu/recover_gpu.py) использует OpenCL. Требуется совместимая видеокарта и драйвер с поддержкой OpenCL.

```powershell
python -m pip install -r ./research/gpu/requirements.txt
python ./research/gpu/recover_gpu.py --selftest
```

Selftest проверяет GPU-вычисления относительно CPU-реализации на синтетических задачах с неизвестными хвостами длиной 2, 3, 5 и 6 байтов, включая границы диапазонов. Долгий подбор запускайте только после успешного selftest на используемом устройстве.

### Подготовка задачи

Создайте каталог с `manifest.json` и зашифрованными файлами в `data/`. Структура manifest приведена в [gpu/manifest.example.json](gpu/manifest.example.json).

Укажите:

- `initial_keystream_hex` — подтверждённый непрерывный префикс потока FEI.
- `files` — входные файлы, их длины FEI и SHA-256.
- `seed_tests` — необязательные проверки известных ключей.
- `chain` — упорядоченные цели, ожидаемый формат, сигнатуру и признак финальной проверки.

Пути в manifest задаются относительно его каталога. Пример содержит заглушки и требует заполнения реальными параметрами задачи.

```powershell
python ./research/gpu/recover_gpu.py --manifest ./private-task/manifest.json --max-gap 6 --batch-power 24
```

| Параметр | Назначение |
|---|---|
| `--manifest` | Путь к JSON-описанию задачи |
| `--device` | Индекс GPU, по умолчанию `0` |
| `--max-gap` | Максимальное число неизвестных байтов, от 1 до 6; по умолчанию 5 |
| `--batch-power` | Размер batch равен `2^N`, допустимо 16–28; по умолчанию 24 |
| `--selftest` | Аппаратная проверка на синтетических данных без manifest |
| `--validate-seed` | Проверка известных ключей и файлов без перебора |

### Сохранение прогресса

После завершённого batch worker атомарно сохраняет `progress.json` рядом с manifest. При повторном запуске продолжает с сохранённой позиции. Незавершённый batch после сбоя проверяется повторно.

Checkpoint привязан к содержимому manifest и версии worker'а. Состояние другой задачи или версии отклоняется. Запускайте только один процесс на один checkpoint. `progress.json` содержит ключевые данные и должен оставаться приватным.

### Ограничения

- Поддерживается непрерывный известный префикс с неизвестным хвостом FEK длиной 1–6 байтов. Произвольные sparse-пропуски требуют другого сценария.
- Каждый дополнительный неизвестный байт увеличивает пространство перебора в 256 раз. Фильтры сигнатур не уменьшают число независимых неизвестных байтов.
- Реализованы проверки PDF, Office ZIP, OLE и JPEG. CAD требует дополнительной проверки в родном приложении.
- Параметры частичного шифрования должны соответствовать исследуемому образцу.
- При полной проверке файл держится в памяти. Для больших файлов заранее оцените необходимую RAM.
- Перед принятием GPU-кандидата выполняются CPU-проверка заголовка, расшифровка и проверка формата. Для финальных PDF-целей выполняется рендер страниц.

## Направления исследований

| Инструменты | Задача |
|---|---|
| `recover_desktop_tree.py` | Массовое восстановление и объединение oracle |
| `metadata_profile_analysis.py`, `reconstruct_fei_model_4f.py` | Структура FEI и гипотезы метаданных |
| `make_gap6_*`, `make_smart_bruteforce_624.py` | Генерация специализированных CPU-worker'ов |
| `solve_*`, `z3_*` | Ограничения Salsa20, известные пары и общие неизвестные байты |
| `target_group_pdf_profile.py`, `pdf_profile_*` | Профили PDF и проверки гипотез plaintext |
| `repair_recovered_videos.py`, `salvage_*` | Мультимедиа и частичное извлечение |
| `zup_*`, `inspect_zup_fei.py`, `try_zup_*` | Исследование зашифрованных резервных копий |

Исторические `run_gap6_*` launcher'ы требуют проверки обработки ошибок и сохранения позиции перед новым длительным прогоном. Частичное извлечение учитывайте отдельно от полной расшифровки.
